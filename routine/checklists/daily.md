# Standing Daily Checklist

The non-negotiables `@daily-routine` schedules and `@checklist-review` audits.

## Wake
- [ ] `@sleep-guardian` morning entry: night report in `pillars/sleep/night-log.md`
- [ ] Hydrate + light mobility
- [ ] `@daily-routine` produces today's plan (or review existing)

## Day
- [ ] Meals per `pillars/nutrition/meal-plan.md` (log each in `nutrition/log.md`)
- [ ] Scheduled training session(s) per `pillars/training/`
- [ ] Scheduled learning block(s) per `domains/` priorities
- [ ] One item toward current sprint goal

## Evening
- [ ] `@activity-log` — narrate the day
- [ ] `@checklist-review` — audit vs evidence, carry over misses
- [ ] `@sleep-coach` wind-down routine start
- [ ] `@sleep-guardian` bedtime watch begins
