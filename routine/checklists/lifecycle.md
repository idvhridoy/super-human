# Domain Lifecycle Checklist

Applied when a new domain enters `domains/` (via `@interest-scout` proposal + human approval).

## Setup
- [ ] Copy `domains/TEMPLATE/` → `domains/<slug>/`
- [ ] `@domain-mentor` drafts `curriculum.md` (L0→L10 path)
- [ ] `@roadmap-planner` sets `roadmap.md` (30/60/90 milestones)
- [ ] `@knowledge-librarian` seeds `resources.md`
- [ ] Add row to `domains/INDEX.md`

## Steady State
- [ ] Sessions logged in `sessions.md` after each practice
- [ ] `metrics.md` updated: hours, streak, level
- [ ] Periodic assessment → `progress.md` level + `learner/assessments.md`

## Sunset (pause/drop a domain)
- [ ] Human decision recorded
- [ ] Status → paused in `domains/INDEX.md` (keep files — progress is never deleted)
