# research/

Deep-research workspace. Owned by `@research-orchestrator`.

## Structure

```
research/<topic-slug>/
├── prompts/              # generated by /research-orchestrator
│   ├── part-01-….md      # ONE paste-ready Gemini/NotebookLM prompt per file
│   ├── …
│   ├── part-10-….md
│   ├── SYNTHESIS.md      # merge prompt for the 10 returned files
│   └── FILE-MAP.md       # part → expected output filename
├── 01-….md … 10-….md     # returned research (human pastes Gemini output here)
└── SYNTHESIS.md          # merged knowledge map + L0→L10 curriculum draft
```

## Workflow

1. Run `/research-orchestrator` + topic → 10 prompts generated.
2. Open 10 Gemini/NotebookLM sessions (parallel accounts) → paste one prompt each.
3. Save each result back as `01-….md` … `10-….md`.
4. Run SYNTHESIS.md → merged playbook.
5. Hand to `@knowledge-librarian` (resources) or `@domain-mentor` (curriculum seed).
