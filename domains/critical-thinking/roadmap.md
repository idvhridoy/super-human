# Critical Thinking Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes. Assumes ~2 sessions/week + daily one-minute "why do I think that?" habit.

## Next 30 days
- [ ] Baseline session: can the learner already give reasons for opinions and spot an obvious fallacy?
- [ ] Complete L0 claim/reason/feeling sorting at 90%+
- [ ] Start L1 argument mapping on short real texts (ads, headlines)
- [ ] Daily habit started: one "why do I think that?" answered out loud

## 60 days
- [ ] L1 passed — 5 real argument maps done
- [ ] Through L2 deduction vs induction exercise
- [ ] L3 fallacy log underway — first real-world instances named with tells
- [ ] Cross-check: `psychology/` bias content pairs naturally; apply here, don't re-teach theory

## 90 days
- [ ] Finish L3 fallacy log (10 instances) and start L4 rhetoric analysis
- [ ] Attempt L5 capstone-style analysis on a real article/debate — verdict defended
- [ ] ~24 sessions logged; evidence-audit practice begun (L6 entry)
- [ ] Calibration predictions started — first 10 scored

## This year
- Target: through L7 probabilistic thinking and into L8 steelmanning
- Stretch: L9 epistemic hygiene audit done; capstone portfolio ≥6 audits; learner reliably applies tools to own beliefs unprompted
