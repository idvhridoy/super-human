# Judgment Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes. Assumes ~2 sessions/week + a daily one-line "what did I decide today and why" habit.

## Next 30 days
- [ ] Baseline session: can the learner already separate a decision from a guess and name evidence for a held position?
- [ ] L0 passed — 10 prompts sorted decision / needs-info / preference
- [ ] L1 started — first decision file with evidence-held / missing / would-flip lists
- [ ] Daily habit running: one real decision logged with its reason

## 60 days
- [ ] L1–L2 done — 3 decision files with facts / claims / unknowns separated and weighted
- [ ] L3 started — first inversion + second-order + opportunity-cost pass on a real choice
- [ ] Decision journal format chosen; first 5 entries written
- [ ] Cross-check: `critical-thinking/` evidence-quality and fallacy content applies here — use it, don't re-teach it

## 90 days
- [ ] L4 probabilistic judgments — 10 scenarios with % confidence scored
- [ ] L5 milestone — 10 journal entries with review dates; format defended
- [ ] First scored predictions returning — calibration baseline emerging (L6 entry)
- [ ] ~24 sessions logged; first adjudication exercise attempted

## This year
- Target: through L7 adjudication and into L8 high-stakes frameworks
- Stretch: L9 pressure decisions clean; capstone audit in progress — the learner is the person people ask "what do you think?", and the answer comes with evidence
