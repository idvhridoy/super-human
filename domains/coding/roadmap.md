# Coding Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes. Assumes ~3 sessions/week (~13 sessions per 30 days). Prereq note: typing speed (digital-literacy L1+) helps; math L3+ helps for L4 algorithms.

## Next 30 days
- [ ] Baseline: unplugged algorithm exercise + device/dev-environment setup (Python installed, editor chosen)
- [ ] Complete L0 computational thinking; skip/accelerate L1 if learner already reasons algorithmically
- [ ] L1 block coding: one mini-game shipped (or straight to L2 if age/aptitude warrants)
- [ ] Start L2 Python basics: variables, types, first 5 small programs

## 60 days
- [ ] Finish L2: 10 small programs + tracebacks read calmly
- [ ] Into L3: loops, functions, lists/dicts; build the CLI program (quiz/contact book)
- [ ] ~26 sessions logged; build-rhythm established (code written every session)
- [ ] Set up git locally; first commits on the L3 project

## 90 days
- [ ] Finish L3 with the file-saving CLI project shipped
- [ ] Into L4 algorithms: implement searches/sorts, start the 20-exercise set
- [ ] First code review of own older project — refactor for naming/clarity
- [ ] Project notebook tracking bugs found/fixed and lessons learned

## This year
- Target: L5 automation script in real use + L6 web basics, ~4–6 weeks per level
- Stretch: reach L7 with a multi-file git-managed project and a clean README
