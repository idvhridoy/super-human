# Coding Curriculum

> Maintained by `@domain-mentor`. The full L0→L10 path; each level lists skills, theory, and the assessment that unlocks the next level.
> Python-first path after block coding. Age-appropriate: solo project publishing and external accounts require human approval per `playbook.md`.

## L0 — Computational Thinking (unplugged)
- Concepts: algorithms as step-by-step instructions, decomposition, pattern recognition, debugging mindset
- Skills: write precise instructions for a human to follow (sandwich, maze walk), trace and fix a broken instruction set
- Unlock: written algorithm for a real task that a human follows successfully + fix 3 seeded bugs in instruction sets

## L1 — Block Coding (Scratch-style)
- Concepts: sprites, events, sequences, loops, conditionals, variables, broadcasting
- Skills: build animated scenes and simple games; use loops instead of repeated blocks
- Unlock: ship one complete mini-game or animation with start/win states and at least one variable

## L2 — Python Basics
- Concepts: syntax, variables, types (int/float/str/bool), input/output, comments, errors and how to read them
- Skills: print/input programs, type conversion, string formatting, read a traceback without panic
- Unlock: 10 small programs correct (calculator, greeting, unit converter) + explain each error message fixed

## L3 — Control Flow & Core Data
- Concepts: if/elif/else, for/while loops, functions, parameters/returns, lists, dicts, tuples, string methods, file read/write
- Skills: write multi-function programs; parse a text file; pick the right data structure
- Unlock: build a working CLI program (e.g., quiz game, contact book, expense logger) saving data to a file

## L4 — Algorithms & Data Structures
- Concepts: searching (linear/binary), sorting (bubble/selection/merge concept), big-O intuition, stacks, queues, recursion intro
- Skills: implement searches/sorts by hand, estimate complexity, trace recursive calls
- Unlock: algorithm problem set (20+ exercises) at 80%+ and explain why binary search is faster in writing

## L5 — Scripts & Automation (intermediate milestone)
- Concepts: libraries/modules, pip and virtual environments, error handling (try/except), JSON/CSV, reading APIs (GET, read-only keys)
- Skills: install and import packages, parse structured data, write a script that automates a real repetitive task
- Unlock: ship a useful automation script (rename files, scrape a public page politely, summarize data) with error handling

## L6 — Web Basics
- Concepts: HTML structure, CSS styling, how browsers/servers work, HTTP basics, intro JS or Python web (Flask-style routes)
- Skills: build a static multi-page site; serve a tiny dynamic app locally
- Unlock: personal mini-site with 3+ pages styled consistently OR a local web app with 2+ routes

## L7 — Real Projects I
- Concepts: multi-file programs, modules/packages, git (init/commit/branch/diff), README writing, planning before coding
- Skills: split code into modules, commit cleanly with good messages, recover from a bad change
- Unlock: project repo with 10+ clean commits, README, and a working feature set built to a written plan

## L8 — Testing & Software Craft
- Concepts: unit tests (pytest-style), debugging with breakpoints/logging, refactoring, code smells, naming, docstrings
- Skills: write tests before fixes, refactor for clarity, profile simple slowness
- Unlock: project with test coverage on core logic + a refactored module that demonstrably improved readability

## L9 — Real-World Apps
- Concepts: databases (SQLite), environment variables and secrets handling, security basics (input validation, no secrets in code), deployment concepts
- Skills: CRUD app against a database, safe config handling, README + requirements complete
- Unlock: working database-backed app reviewed against a security checklist; any public deployment is human-approved

## L10 — Mastery: Software Craft
- Concepts: system design basics (components, data flow, trade-offs), code review etiquette, open-source contribution norms
- Skills: design-then-build a portfolio project, review another's code constructively, read an unfamiliar codebase
- Unlock: capstone portfolio project shipped + documented + teach-back session explaining it to a beginner
