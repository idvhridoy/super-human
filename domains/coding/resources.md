# Coding Resources

> Curated by `@knowledge-librarian`, ordered by level. Generic categories — no invented URLs.

## L0–L2 (foundations)
- Unplugged activity books: algorithm card games, maze-instruction challenges (CS-Unplugged-style)
- Scratch-style block platform with community starter projects (age-appropriate, moderated)
- Beginner Python course: interactive, exercises-in-browser style
- Kid-friendly Python book with small projects (games, drawings via turtle)
- Python official tutorial for reference lookups

## L3–L5 (intermediate)
- Exercise platforms with graded problem sets and instant feedback (Codewars/Exercism-style, age-gated signups need human approval)
- Automate-the-boring-stuff-style project book: files, CSV, simple automation
- Algorithm visualizations (animated sort/search demos)
- Python standard-library docs for dicts/files/json
- Beginner API tutorials using free read-only public APIs

## L6–L10 (advanced)
- HTML/CSS/JS interactive course (freeCodeCamp-style)
- Flask-style micro-framework tutorial for Python web apps
- Git/GitHub official guides: init, commit, branch, merge, README conventions
- Pytest-style testing tutorial + debugging-with-breakpoints guides
- SQLite tutorial and secure-coding checklists (input validation, secrets handling)
- Open-source "good first issue" guides for L10 contribution practice
