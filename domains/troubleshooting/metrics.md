## Domain-specific KPIs
- Fault log entries (count) — real breakages documented with problem definitions
- Reproduction rate (%) — faults with working repeatable steps vs attempted
- Isolation tests run (count) — each with predicted-before-run outcome
- Bisection efficiency (tests used vs optimal) — log2(n)+2 benchmark
- Root causes reached (count) — causes whose fix prevents recurrence
- Full-loop reports (count) — define → reproduce → isolate → root → fix → verify → document
- Fix verification rate (%) — fixes confirmed via the original reproduction steps
- Domains covered (count) — device / code / system / process / plan breadth
- Recurrence rate (%) — fixed faults that returned (lower = better root-cause quality)
