# Language Mastery Playbook

> Do/don't list maintained by `@domain-mentor` from session evidence.

## Do
- Practice daily in micro-sessions: 15+ minutes beats a weekly cram
- Use spaced repetition for vocabulary; review before adding new words
- Speak aloud every session, even alone — mouths need reps, not just eyes
- Anchor words to images/contexts, not translation pairs
- Log every new word and phrase in sessions.md evidence
- Use the target language in real moments: greet, count, label objects
- Celebrate small wins: first full sentence, first joke understood

## Don't
- Don't binge-study then skip days — streak decay kills retention
- Don't translate word-for-word in the head past L3; build direct associations
- Don't fear mistakes — errors are the training data
- Don't rely on one app/source; mix input types (audio, text, speech)
- Don't chase rare vocabulary before core words are automatic
- Don't test every session — assess weekly, practice daily
