# Strategy & Decisions Resources

> Curated by `@knowledge-librarian`, ordered by level. Generic categories — specific titles/URLs added after librarian review (never invent links).

## L0–L2 (foundations)
- Beginner explainers on decision-making (short videos/articles for young readers).
- Printable templates: weighted pros/cons sheet, options-map worksheet, project-planning one-pager.
- Everyday-decision scenario decks for option-listing practice.
- A simple decision-journal template (options / reasoning / confidence / review date).
- Intro reading on process vs outcome (luck vs skill) at concept level.

## L3–L5 (intermediate)
- A friendly introduction to game theory: prisoner's dilemma, zero-sum vs win-win, repeated games — books, videos, or interactive demos.
- Playable classics for hands-on analysis: strategy board/card games with clear payoffs (plus family/mentor game nights).
- Probability-intuition exercises: estimation quizzes with verifiable answers, expected-value puzzles.
- Calibration-test sets for the L4/L5 probability assessments.
- A growing decision-journal archive folder + review-checklist.

## L6–L10 (advanced)
- Negotiation primers covering BATNA, trades vs concessions, perspective-taking exercises.
- Scenario-planning and premortem guides with worked examples.
- A readable popular book on judgment/decision-making or forecasting skill.
- Second-order-thinking essay/article collections with practice prompts.
- Project strategy-doc template: goal / options / risks / scenarios / triggers / review plan.
- Optional crossover reading: accessible strategy classics summarized at age-appropriate depth.
