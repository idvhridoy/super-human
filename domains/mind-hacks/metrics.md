## Domain-specific KPIs
- State-check entries (count) — daily state naming; target 3+/day at L0
- Time-to-calm (seconds) — protocol start → self-rated calm; track trend down
- Protocol uses in real events (count) — calm/regulation/routine deployed outside practice
- Pre-performance routine adherence (%) — events where routine actually ran
- Pressure-simulation results — pass/fail + which tools fired
- Decision-journal entries (count) — call + reason + confidence logged
- Biases caught mid-thought (count) — named in the moment, not just in hindsight
- Persuasion attempts spotted (count) — lever named; pause-instead-of-comply rate (%)
- Decision-journal calibration (%) — predicted confidence vs actual outcome
