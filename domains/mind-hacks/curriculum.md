# Mind Hacks Curriculum

> Maintained by `@domain-mentor`. The full L0→L10 path; each level lists skills, theory, and the assessment that unlocks the next level.
> Framing rule for every level: **self-mastery only**. These are tactics the learner applies to their own mind under real-world pressure — never tools for manipulating other people. `psychology/` explains how the mind works, `mindfulness/` builds the breath practice, `brain-training/` drills raw capacity — this domain deploys them tactically, in the moment.

## L0 — Foundations: State Awareness
- Skills: notice and name own mental state (calm, wired, flat, scattered) on cue; spot the body signals that announce each state.
- Theory: state ≠ identity — "I am in a wired state" not "I am an anxious person"; performance is state-dependent; you can't steer what you don't notice.
- Assessment: state log for 1 week — 3+ entries/day naming state + body signal + what triggered it.

## L1 — Calm-Under-Pressure Protocol
- Skills: physiological sigh / extended-exhale breathing; 5-4-3-2-1 grounding; a 60-second personal calm-down sequence.
- Theory: breathing controls arousal faster than thinking does; exhale-dominant breaths downshift the stress response; grounding returns attention to the present.
- Assessment: demonstrate the full protocol on demand; use it in 3 real mild-stress moments and log time-to-calm each.

## L2 — State Management (Up & Down)
- Skills: read own arousal level on a 1–10 scale; apply up-regulation (movement, cold water, energizing breath) and down-regulation tools deliberately.
- Theory: the arousal curve — too flat and too wired both hurt performance; each task has an optimal zone; sleep, caffeine, food, and screens all move the dial.
- Assessment: 5-day experiment — deliberately up-regulate before one task and down-regulate before another; log perceived performance each time.

## L3 — Pre-Performance Routines
- Skills: design a short repeatable routine (2–5 min) run before tests, presentations, or matches.
- Theory: routines shrink decision fatigue and signal "game time" to the brain; consistency beats complexity; elite performers ritualize the minutes before performance.
- Assessment: written routine + evidence of use before 3 real events; refine once based on what actually helped.

## L4 — Thinking Fast: Tools for Time Pressure
- Skills: chunking under load; first-principles thinking when the script fails; checklists for repeated situations.
- Theory: working memory collapses under pressure — externalize (write it down); chunking compresses; when memorized steps fail, drop to "what is actually true here?" and rebuild.
- Assessment: timed-pressure drill set (e.g., rapid questions, puzzle under countdown) — use chunking + checklist and beat own unaided baseline.

## L5 — Intermediate milestone: The Pressure Protocol
- Skills: run the full stack live — detect state → calm or energize → pre-performance routine → fast-thinking tools — inside one simulated pressure event.
- Theory: integration of L0–L4; tools must chain automatically or they won't fire when it matters.
- Assessment: pass a designed pressure simulation (timed challenge + audience/distraction) while narrating which tools fired; `@domain-mentor` reviews the log.

## L6 — Cognitive-Bias Self-Defense
- Skills: catch own biases mid-thought — confirmation, sunk cost, halo effect, affect heuristic; start a decision journal (call + reason + confidence, reviewed later).
- Theory: biases are invisible in the moment; the tell is usually emotional certainty or a story that feels too clean; journaling turns hindsight into foresight.
- Assessment: decision journal with 10+ entries; at least 2 entries where the learner caught a bias changing their call and named it.

## L7 — Persuasion-Attempt Detection
- Skills: spot persuasion levers aimed at you — scarcity, urgency, social proof, authority, reciprocity, flattery, fear — in ads, sales pitches, messages, and social feeds.
- Theory: persuasion is constant and mostly legal; the defense is *naming the lever* — once labeled, its grip weakens; strong emotion + time pressure = someone's playbook, not your interest.
- Assessment: persuasion log — 10 real attempts identified, lever named, and response noted; at least 3 where the learner paused instead of complying.

## L8 — Decision Shortcuts (and Their Failure Modes)
- Skills: apply fast heuristics deliberately — satisficing, 10/10/10 rule, inversion ("how would this fail?"), two-minute expected-value math — and state when each breaks.
- Theory: every shortcut trades accuracy for speed; mastery is knowing the failure mode, not just the trick; reversible decisions deserve speed, irreversible ones deserve slowness.
- Assessment: apply 4 different shortcuts to 4 real decisions; write each one's failure mode and whether it applied.

## L9 — Pressure Inoculation
- Skills: graduated self-exposure to evaluative stress (bigger audiences, tighter clocks, real stakes); post-failure recovery protocol — decompression, honest review, next rep.
- Theory: stress inoculation — tolerance is built in graded doses; a debriefed failure builds more skill than an easy win; confidence is evidence, not pep talk.
- Assessment: completed inoculation ladder (3 escalating pressure events logged) + one debriefed failure with a written lesson extracted.

## L10 — Mastery: Personal Mental-Performance Playbook
- Skills: maintain a written playbook — calm protocol, up/down regulation menu, pre-performance routine, bias defenses, decision toolkit — and deploy it reliably.
- Theory: synthesis — the learner knows their own pressure signature, which tools fire for them, and the hard limits (fatigue, overwhelm → escalate, don't push).
- Assessment: capstone — playbook presented + demonstrated in one real high-stakes event (exam, competition, performance) + teach one technique to someone else successfully.
