# Running Curriculum

> Maintained by `@domain-mentor`. The full L0→L10 path; each level lists skills, theory, and the assessment that unlocks the next level.

## L0 — Foundations
- Skills: 30-min brisk walk without fatigue; correct footwear; tall posture, relaxed shoulders, eyes forward.
- Theory: RPE scale (1–10), talk test, what a warm-up/cool-down is.
- Unlock assessment: 30-min continuous brisk walk at RPE ≤4 + name the 5 warm-up moves.

## L1
- Skills: walk/run intervals — 1 min easy run / 2 min walk ×8; dynamic warm-up routine memorized.
- Theory: easy vs hard days; nasal vs mouth breathing; hydration basics.
- Unlock assessment: complete a 20-min interval session finishing all run segments at conversational pace.

## L2
- Skills: extend run segments — 3/1 then 5/1 run-walk; even pacing (not sprinting starts).
- Theory: weekly structure (hard/easy alternation); cadence concept (~160–170 steps/min intro).
- Unlock assessment: 30-min session with run segments ≥3 min, or 15-min continuous easy jog.

## L3
- Skills: build to 20-min continuous running; basic running form drills (high knees, butt kicks, strides).
- Theory: why recovery days exist; sleep + running; shin-splint warning signs.
- Unlock assessment: 20-min continuous run at talk-test pace.

## L4
- Skills: first 5k continuous; pacing a full distance — start slow, finish even.
- Theory: negative splits; pacing charts; race-day nerves management.
- Unlock assessment: 5k continuous run/walk-free at any pace.

## L5 — Intermediate milestone
- Skills: consistent 3 sessions/week; weekly volume 12–15 km; one longer run (7–8 km).
- Theory: 10% volume-increase rule; easy/hard polarisation; cross-training value.
- Unlock assessment: 4 consecutive weeks logged at 3 sessions/week + 5k time improvement vs L4 baseline.

## L6
- Skills: 8–10k long run; tempo run intro (20 min comfortably-hard); strides after easy runs.
- Theory: tempo/threshold concept; fuelling for >60 min efforts; terrain effects.
- Unlock assessment: 8k continuous run + one logged tempo session.

## L7
- Skills: 10k continuous; interval work — 6×400 m at faster-than-5k pace with jog recoveries; fartlek.
- Theory: VO2 intervals vs tempo vs easy — purpose of each; heart-rate zones.
- Unlock assessment: 10k continuous run + completed interval session within paces.

## L8
- Skills: hill repeats (6×30–45 s uphill strong effort); trail/uneven-surface running basics.
- Theory: hill running form; strength-endurance link; downhill control.
- Unlock assessment: 10k route including hills completed, or 12k flat continuous.

## L9
- Skills: long runs 14–16 km; sustained race-pace segments; running by feel without a watch.
- Theory: tapering; race strategy; periodization of a training block.
- Unlock assessment: 15k continuous run, or half-marathon distance completed.

## L10 — Mastery
- Skills: designs own 8–12 week training block; paces by feel within ±10 s/km; mentors a beginner through a session.
- Theory: full periodization, injury-prevention screening, age-adjusted performance targets.
- Unlock assessment: completed self-designed block with logged evidence + teach-back session documented.
