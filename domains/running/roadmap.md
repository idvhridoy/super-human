# Running Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes.

## Next 30 days
- [ ] Baseline: 30-min brisk walk assessment (L0 unlock)
- [ ] 2–3 walk/run interval sessions per week, all logged in `sessions.md`
- [ ] Dynamic warm-up routine memorized and used every session
- [ ] Reach L1 → start L2 intervals (3/1 run-walk)

## 60 days
- [ ] 15–20 min continuous easy jog achieved (L3 unlock in progress)
- [ ] Consistent 3 sessions/week for 4 consecutive weeks
- [ ] First form-drill session (high knees, butt kicks, strides)

## 90 days
- [ ] First continuous 5k (L4 unlock)
- [ ] Weekly volume 10–15 km with no missed-week gaps
- [ ] Long-run slot established (one run 20–30% longer than others)

## This year
- Target L6–L7: 10k continuous, tempo + interval sessions in the weekly mix, and a full season (12 weeks) of consistent logged running.
