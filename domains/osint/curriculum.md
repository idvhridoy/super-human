# OSINT Curriculum

> Maintained by `@domain-mentor`. The full L0→L10 path; each level lists skills, theory, and the assessment that unlocks the next level. Scope: open-source intelligence — finding, verifying, and reporting information from PUBLIC sources only. The learner becomes a researcher whose findings others can re-verify and trust.
>
> **HARD RULE — applies at every level and is taught before any technique:** public sources only. Never stalk, follow, monitor, or harvest private individuals. Never bypass access controls, create fake accounts, scrape against terms of service, or dox anyone. Purposes: defensive security awareness, research, and verification ONLY. Comply with applicable law (computer-misuse, privacy, data-protection). When in doubt: `## NEXT: human-consult`. Violating this rule ends the domain, not just the lesson.
>
> `digital-literacy/` owns internet/media basics; `critical-thinking/` owns evidence-quality theory — applied here to structured public-source research.

## L0 — Foundations: What OSINT Is (and Isn't)
- Skills: define open-source intelligence; classify information as public vs private; recite the ethical red lines from memory.
- Theory: public ≠ fair game — public data about private people still has ethical limits; OSINT exists for defense, research, and verification, never for snooping on people.
- Assessment: ethics-first exam — sorts 20 research actions into allowed / not-allowed / needs-human-review; explains WHY each red line exists.

## L1 — Public-Source Fundamentals
- Skills: identify primary public sources — official records, published reports, government databases, court filings, press releases.
- Theory: primary beats secondary; the best research answers come from boring official sources, not clever tricks.
- Assessment: for 5 research questions, name the correct primary public source and retrieve one real answer with citation.

## L2 — Search Operators & Advanced Queries
- Skills: use search operators (quotes, site:, filetype:, minus, OR), date filters, and multi-engine searching.
- Theory: the query is the skill — most "hidden" info is simply unqueried public info; each engine indexes differently.
- Assessment: query worksheet — 10 retrieval tasks solved, each with the specific operator combination documented.

## L3 — Source Verification Basics
- Skills: corroborate a claim across independent sources; distinguish corroboration from circular reporting.
- Theory: one source is a claim, two independent sources is a lead, three is a finding; sites repeating the same origin aren't independent.
- Assessment: verification log — 5 claims each traced to independent sources; one circular-reporting chain correctly flagged.

## L4 — Image & Metadata Basics
- Skills: reverse image search; read basic image metadata; narrow a photo's origin using visible clues (signage, language, terrain, architecture).
- Theory: images carry context beyond pixels; metadata can be stripped or faked — treat as lead, not proof; geolocation inferences stay labeled and proportionate — public events/places only, never private homes or people's whereabouts.
- Assessment: 5 image exercises — origin identified with reasoning chain + stated confidence; exercises use public-event/stock images only, never photos of private individuals.

## L5 — Intermediate milestone: Public-Footprint Profiling (Orgs & Public Figures Only)
- Skills: build a structured profile of an ORGANIZATION or public figure from public sources — registrations, publications, official channels, public statements.
- Theory: footprint profiling is legitimate for orgs, public entities, and due diligence; private individuals are OFF-LIMITS for profiling exercises — the line is public role and consent.
- Assessment: mini-profile of one public organization — sourced claims only, every fact cited, plus a section listing what was deliberately NOT investigated and why.

## L6 — Verification Chains
- Skills: document provenance for every claim — where found, when, source type, corroboration status, confidence level.
- Theory: the chain IS the intelligence — an unsourced fact is an opinion; confidence labels (confirmed / likely / possible / unverified) are mandatory.
- Assessment: 10-fact dossier with full provenance chains; mentor attempts to break 3 chains — learner defends or downgrades honestly.

## L7 — Research Workflow & Tooling
- Skills: run a repeatable workflow — question → sources → collection → verification → notes; maintain auditable collection logs; manage own researcher footprint ethically (no fake personas — ever).
- Theory: process beats cleverness; collection is logged so findings are re-verifiable by a third party.
- Assessment: run the full workflow on one assigned question; produce auditable notes — every artifact traced to its search path.

## L8 — Defensive OSINT: Auditing Your Own Footprint
- Skills: audit the learner's/household's public exposure; document what a stranger could learn; produce a reduction plan.
- Theory: defensive OSINT is the flagship ethical use — you protect by knowing what's exposed; audit only yourself, or another person ONLY with their explicit informed consent.
- Assessment: own-footprint report (guardian consent if ward) — exposures listed, severity rated, reduction actions proposed; `## NEXT: human-consult` for anything sensitive found.

## L9 — Structured OSINT Reporting
- Skills: write a full OSINT report — executive summary, scope, method, findings with confidence labels, provenance appendix, limitations.
- Theory: a report is judged by whether a skeptical reader can re-verify every claim; the limitations section builds trust, not weakness.
- Assessment: one complete report on an assigned org/public-event question — passes re-verification (mentor re-checks 5 claims; all trace back).

## L10 — Mastery: Full OSINT Engagement (capstone)
- Skills: run an end-to-end ethical engagement — scope, collect, verify, report — on a real question about a public organization, event, or the learner's own footprint.
- Theory: synthesis — the trusted researcher shows sources, labels confidence, respects limits, and writes limitations honestly.
- Assessment: capstone report — scoped question, auditable collection log, verification chains, confidence-labeled findings, limitations, ethics-compliance statement; mentor re-verification ≥90%; presented to a human reviewer.
