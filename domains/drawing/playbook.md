# Drawing & Visual Arts Playbook

> Do/don't list maintained by `@domain-mentor` from session evidence.

## Do
- Deliberate repetition: drills before subjects, warm-ups before pieces
- Draw from life first, photo reference second, imagination third (until L9)
- Keep every drawing — dated sketches are the progress evidence
- Work big-to-small: block in shapes/proportions before any detail
- Step back often: check proportions and values from a distance
- Study references and masters — copying to learn is legitimate training
- End sessions on a small win, not a frustrated abandon

## Don't
- Don't erase every "mistake" — draw over it; errors teach proportion
- Don't rely on tracing as the main method; use it rarely for analysis only
- Don't compare L2 work to professional portfolios — compare to last month's page
- Don't skip fundamentals to chase fancy subjects (characters before gesture = shaky figures)
- Don't detail one corner while the rest is blank — keep the whole drawing at one stage
- Don't grind through frustration past ~45 min; switch to a drill or stop

## Safety notes (if physical)
- Posture check: neutral wrist, break every 30–40 min to prevent strain. Ventilation if using fixatives/solvents (adult approval for those materials).
