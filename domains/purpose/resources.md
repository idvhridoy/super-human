# Purpose Resources

> Curated by `@knowledge-librarian`, ordered by level.

## L0–L2 (foundations)
- Values card-sort deck: ~50 value cards (honesty, freedom, mastery, family, adventure, service, security, creativity...) with ranking protocol
- Values-in-action journal: "where did this value actually show up this week?"
- Strengths inventory worksheets: evidence-first format (strength → proof → source)
- Curiosity log template linked to `learner/interests.md`: what absorbed me, what I returned to, what I dropped
- Feedback-gathering script: "what do you think I'm good at?" — asking 3 trusted people, recording verbatim

## L3–L5 (intermediate)
- Ikigai diagram template: four circles (love / good at / needed / paid) with overlap labels and honest-blank rules
- Ikigai explainer readings adapted for the learner's age — framework as lens, not verdict
- Contribution experiment menu: help, build, teach, fix, organize — small scoped options per `learner/schedule.md`
- Contribution reflection log: experiment → who benefited → how it felt (energized/neutral/drained) → why
- Mission-statement drafting guide: who I serve + how + why it matters, ≤3 sentences, draft-flagged
- `learner/goals.md` — live goal list the mission must link to

## L6–L10 (advanced)
- Mission-test experiment design sheet: hypothesis → cheap test → evidence → confirm/revise
- Quarterly alignment review template: values + mission vs goals/schedule/habits → keep/adjust/drop edits to `learner/goals.md`
- Borrowed-purpose checklist: "for whom am I doing this?" — parental, peer, status, and default-path scripts to examine
- Purpose-revision worksheet: what changed, what evidence changed it, keep-or-update with reasoning
- Peer-guiding script for L9: running a values sort for someone else without prescribing
- Purpose charter template (capstone): values ranked, mission stated, contribution commitments, review rhythm, `learner/goals.md` links
- Coordination: `@career-mentor` for career-path implications; `domains/psychology/` for wellbeing context — referenced, never repeated
