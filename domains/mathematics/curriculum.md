# Mathematics Curriculum

> Maintained by `@domain-mentor`. The full L0→L10 path; each level lists skills, theory, and the assessment that unlocks the next level.
> **Foundational domain:** math gates other domains — physics needs L4+, engineering needs L3+, strategy/finance need L3+, coding needs L3+. Prioritize pace here when scheduling conflicts arise.

## L0 — Number Sense & Foundations
- Concepts: counting, place value (ones–thousands), number line, comparing/ordering, rounding, odd/even, estimation
- Skills: mental counting forwards/backwards, skip-counting, estimate-then-check habit
- Unlock: place-value + estimation diagnostic at 90%+ and explain a number's value by digits

## L1 — Arithmetic Fluency
- Concepts: addition/subtraction/multiplication/division, fact families, order of operations intro, remainders
- Skills: times tables to 12×12 fluent, multi-digit vertical arithmetic, one-step word problems
- Unlock: timed arithmetic sheet at 90%+ with no careless-sign errors; times-table recall < 3s per fact

## L2 — Fractions, Decimals, Percentages
- Concepts: equivalent fractions, common denominators, fraction↔decimal↔percent conversion, ratios intro
- Skills: add/subtract/multiply fractions, decimal arithmetic, find X% of a quantity
- Unlock: mixed fraction/decimal/percent problem set at 85%+ and convert any form to any other

## L3 — Pre-Algebra (gates engineering/strategy/finance tracks)
- Concepts: variables, expressions, simple equations, negative numbers, ratios & proportions, exponents intro, coordinate plane
- Skills: simplify expressions, solve one/two-step equations, plot points, set up a proportion
- Unlock: pre-algebra assessment at 80%+ and set up equations from 5 word problems correctly

## L4 — Algebra I (gates physics)
- Concepts: linear equations/inequalities, slope and graphing, systems of equations, factoring, quadratics intro, exponents & roots
- Skills: solve/graph lines, solve systems 2 ways, factor quadratics, quadratic formula
- Unlock: algebra problem set at 80%+ across all subtopics + interpret a real-world graph (e.g., cost vs units)

## L5 — Geometry (intermediate milestone)
- Concepts: points/lines/angles, triangles, quadrilaterals, circles, perimeter/area/volume, Pythagoras, congruence & similarity, transformations
- Skills: compute areas/volumes, apply Pythagoras, construct similar-figure proportions, basic compass/straightedge constructions
- Unlock: geometry problem set at 80%+ + measure a real object/room and compute its area correctly

## L6 — Algebra II & Functions
- Concepts: polynomials, rational expressions, exponentials & logarithms, sequences & series, function notation, inverses
- Skills: manipulate polynomials, solve exponential/log equations, model growth/decay, sum arithmetic/geometric series
- Unlock: functions assessment at 80%+ and model one real growth scenario (population, savings) correctly

## L7 — Statistics & Data Literacy
- Concepts: mean/median/mode, variance/standard deviation, distributions, probability basics, correlation vs causation, sampling bias
- Skills: compute summary statistics, read/build histograms and scatter plots, basic probability (independent/compound), spot misleading charts
- Unlock: analyze a real dataset (sports, weather, prices) + written critique of one misleading statistic/chart

## L8 — Trigonometry & Precalculus
- Concepts: unit circle, sin/cos/tan, radians, trig identities basics, vectors intro, limits intuition
- Skills: solve right/oblique triangles, evaluate trig on unit circle, vector add/scale, describe limit behavior
- Unlock: trig problem set at 80%+ + explain why 0.999… = 1 or a similar limit intuition in writing

## L9 — Calculus
- Concepts: limits formalized, derivatives, chain/product rules, applications (optimization, related rates), integrals, Fundamental Theorem
- Skills: differentiate/integrate standard functions, optimize a real quantity, compute area under a curve
- Unlock: calculus problem set at 80%+ + one applied optimization problem solved end-to-end

## L10 — Mastery: Proofs & Problem-Solving
- Concepts: proof techniques (direct, contradiction, induction), olympiad-style heuristics (invariants, extremes, pigeonhole), synthesis across all prior topics
- Skills: write a clean proof, solve multi-domain competition problems, identify which tools a problem calls for
- Unlock: capstone — solve a mixed competition-style set + write 3 valid proofs + teach-back of one full topic arc to a beginner
