# Mathematics Playbook

> Do/don't list maintained by `@domain-mentor` from session evidence.

## Do
- Practice daily — short frequent sessions beat weekend cramming; never skip the 10-min mental-math drill
- Show all work on paper; the written steps ARE the skill, not decoration
- Keep an error log: every missed problem recorded, re-solved at 48h, again at 1 week
- Estimate before solving, sanity-check after ("does this answer make sense?")
- Mix problem types within a set (interleaving) — don't grind 30 identical problems
- Use concrete objects/drawings for new concepts (fractions = cut paper, negatives = number line)
- Check answers by a second method when possible (inverse operation, plug-back)

## Don't
- Don't start a new level with the previous assessment below its unlock threshold
- Don't skip word problems — translating words → equations is the core real-world skill
- Don't let the learner memorize procedures without asking "why does this work?"
- Don't use calculators before L6; after that, calculator for arithmetic only, never for understanding
- Don't rush fluency drills into anxiety — untimed first, timed once confident
- Don't accept "I guessed right" — correct answers without valid work don't count

## Safety notes (if physical)
- N/A — seated study; watch posture and session length (short breaks every 25–30 min)
- Math anxiety is a real blocker: if frustration spikes, drop difficulty one level and rebuild momentum — wellbeing over metrics
