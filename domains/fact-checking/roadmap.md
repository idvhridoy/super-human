# Fact-Checking Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes. Assumes ~2 sessions/week plus a daily verification habit on real content the learner encounters.

## Next 30 days
- [ ] Baseline session: can the learner already extract a core claim and name a trustworthy source type?
- [ ] L0 claims-vs-facts sorting passed at 90%+ → L0 done
- [ ] Verification reflex log started (L1) — first flagged claims recorded
- [ ] Daily habit: one "before I believe/share this — checked?" pause per day

## 60 days
- [ ] Reflex log at 10+ entries → L1 done
- [ ] L2 source evaluation passed — primary sources identified for 5 claims
- [ ] L3 triangulation exercise underway; independence-vs-echo demonstrated
- [ ] Cross-check: `digital-literacy/` feeds/ads basics already in place — reference, don't re-teach

## 90 days
- [ ] L3 done; L4 lateral-reading timed drill passed (≤5 min/source)
- [ ] L5 media verification — 5 images/videos traced to earliest source
- [ ] L6 manipulation log underway — first tactics named with emotional hooks identified
- [ ] First full-method fact-check attempted (L8 seeded)

## This year
- Target: through L7 agenda-driven framing and into L8 full method — two complete written fact-checks done
- Stretch: L9 publishable reports drafted; capstone investigation scoped; the verify-before-share reflex runs unprompted in daily life
