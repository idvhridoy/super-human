# Fact-Checking Curriculum

> Maintained by `@domain-mentor`. The full L0→L10 path; each level lists skills, theory, and the assessment that unlocks the next level.
> Framing rule: the fact-checker vs manipulation — verify before believing AND before sharing. Non-partisan and evidence-first at every level: the same method applies to claims you love and claims you hate. `digital-literacy/` owns media-literacy basics (what a URL is, how feeds work, ads vs content) and `critical-thinking/` owns argument analysis — this domain builds the verification workflow on top of both. Reference them, never repeat them.

## L0 — Foundations: Claims vs Facts
- Skills: tell a checkable factual claim from an opinion, prediction, or feeling; spot the exact claim inside a post/headline/meme.
- Theory: only checkable claims can be fact-checked; "verifying" means finding evidence independent of the source making the claim; a fact is boring and repeatable — a viral claim is engineered not to be.
- Assessment: sort 20 mixed statements into checkable-claim / opinion / prediction / feeling at 90%+; extract the single core claim from 5 real posts.

## L1 — The Verification Reflex
- Skills: pause before believing AND before sharing; run the 60-second check (who says this, where else does it appear, what's the original source).
- Theory: sharing is publishing — you are the last editor; emotional reaction speed is the manipulator's advantage; "I'll check later" means the claim already won.
- Assessment: 2-week reflex log — every claim the learner nearly believed or shared without checking, flagged and checked; at least 10 entries.

## L2 — Source Evaluation
- Skills: grade a source's reliability for a given claim; distinguish primary, secondary, and junk sources; check date and context of origin.
- Theory: the best source is closest to the event/data; expertise must match the claim type; a real outlet can still publish a false story; old-true-recycled-as-new is a top deception pattern.
- Assessment: for 5 claims, identify the primary source and grade each layer of reporting between it and the post that carried it.

## L3 — Source Triangulation
- Skills: confirm or kill a claim using 3+ independent sources; detect when "many sources" are all copying one wire/single origin.
- Theory: independence is the point — ten outlets repeating one report is one source; genuine triangulation means different reporters, different evidence, same conclusion; silence from independent sources is itself a signal.
- Assessment: triangulation exercise — 5 claims resolved confirmed/refuted/unresolved, each with the independence of sources demonstrated, not assumed.

## L4 — Lateral Reading
- Skills: leave the page — open new tabs to check what trusted outsiders say about the source, author, and claim; use search engines and fact-check databases deliberately.
- Theory: a site tells you what it wants you to think about it; professional fact-checkers spend more time off the page than on it (Stanford research); "about us" pages, Wikipedia entries, and prior fact-checks are leverage.
- Assessment: timed drill — 10 unfamiliar sources judged trustworthy/mixed/unreliable in ≤5 min each via lateral reading only, verdicts compared against `@domain-mentor`'s reference list.

## L5 — Image & Video Verification
- Skills: reverse image search; check video origin, date, and location claims; spot basic edits, miscaptioning, and context theft.
- Theory: most viral visual "evidence" is real footage with a false caption — wrong place, wrong date, wrong event; the image is rarely fake, the story attached to it is; verification = find the earliest version.
- Assessment: verify 5 circulating images/videos to earliest-known source; at least one shown to be miscaptioned real media.

## L6 — Disinformation Patterns & Emotional Manipulation
- Skills: name the recurring playbooks — repetition flooding, manufactured consensus, fake experts/organizations, false flags, rage-bait, urgency ("share before they delete this"), flattery, identity triggers.
- Theory: disinformation is manufactured, targeted, and funded — it exploits emotion to bypass verification; the tell is usually emotional intensity disproportionate to evidence; manipulation tactics depth lives in `psychology/` — applied here to real content.
- Assessment: manipulation log — 10 real pieces of content mapped to the specific tactic(s) used, with the emotional hook identified in each.

## L7 — Agenda-Driven Framing
- Skills: detect framing devices — word selection, what was omitted, whose voice is quoted, what's the implied villain/hero; reconstruct the same facts under a neutral frame; ask who benefits if this framing wins.
- Theory: true facts can be arranged to mislead — selection and emphasis are manipulation without lying; every source has an agenda (commercial, political, tribal); the question is not "biased or not" but "which direction, and how hard."
- Assessment: frame-comparison exercise — one event covered by 3 differently-motivated outlets; the learner writes the neutral version and names each outlet's frame.

## L8 — The Full Fact-Check Method
- Skills: decompose a multi-part claim; build an evidence file; apply a verdict taxonomy honestly (true / mostly true / misleading / mostly false / false / unverifiable).
- Theory: a fact-check reports the method, not just the verdict — claim, evidence consulted, reasoning, verdict, confidence; "unverifiable" is a legitimate terminal answer; corrections are part of the craft, not a failure.
- Assessment: two complete written fact-checks using the method template — claim decomposition, evidence file, verdict with confidence, source list.

## L9 — Writing the Fact-Check Report
- Skills: write for a reader — plain verdict up top, evidence trail visible, method stated, uncertainty honest; write a correction correctly.
- Theory: the report's job is making the reader more accurate in 90 seconds; cite what a reader can check themselves; a good fact-check teaches the method by showing it.
- Assessment: 3 publishable-quality fact-check reports (claim → evidence → verdict → sources), one containing a self-correction or revision handled transparently.

## L10 — Mastery: Fact-Check Capstone
- Skills: run an end-to-end investigation — pick a live circulating claim, decompose it, triangulate, verify media, identify the manipulation playbook, publish the report.
- Theory: synthesis — the fact-checker's output is calibrated public judgment; speed matters but never outranks accuracy; the craft's ethics are non-partisan evidence-first or nothing.
- Assessment: capstone — a published-quality fact-check report on a real claim (multi-part, includes visual media, includes agenda analysis), plus a live verification demonstration timed and scored by `@domain-mentor` at 90%+ on method correctness.
