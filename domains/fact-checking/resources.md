# Fact-Checking Resources

> Curated by `@knowledge-librarian`, ordered by level.

## L0–L2 (foundations)
- Claim-sorting drill sets: mixed checkable/opinion/prediction statements
- "Find the core claim" exercise deck using real headlines and posts (sanitized for age)
- Verification-reflex log template: claim → nearly believed/shared? → check run → result
- Source-type reference card: primary vs secondary vs junk, with examples
- `domains/digital-literacy/` — prerequisite basics: feeds, URLs, ads vs content (reference only)

## L3–L5 (intermediate)
- Fact-check databases and professional outlets for comparison: Snopes, PolitiFact, Full Fact, AFP Fact Check, Reuters Fact Check
- Lateral-reading drill kit: 10+ unfamiliar source domains with reference verdicts
- Reverse image search tools: Google Lens, TinEye, Yandex Images
- Video verification primers: earliest-upload tracing, keyframe search, InVID/WeVerify plugin (desktop, supervised)
- Stanford lateral-reading research summary (Civic Online Reasoning)

## L6–L10 (advanced)
- Disinformation playbook primers: NATO/strategic-communications overviews, First Draft News archives, "The Media Manipulation Casebook"
- Frame-comparison exercise sets: same event across differently-motivated outlets
- Fact-check method template: claim decomposition → evidence file → verdict taxonomy → confidence → sources
- Publishable-report exemplars: professional fact-checks annotated to show structure
- Capstone kit: live-claim selection criteria, investigation checklist, report format, scoring rubric
- `domains/critical-thinking/` L6 evidence-quality material — shared foundation, referenced not repeated
