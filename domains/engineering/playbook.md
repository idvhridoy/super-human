# Engineering & Making Playbook

> Do/don't list maintained by `@domain-mentor` from session evidence.

## Do
- Measure twice, cut once — enforce marking-out before every cut
- Keep a design notebook: sketch → materials → test result → what to change
- Test to failure deliberately at low stakes (card bridges) to learn load behavior
- Clean and return tools after every session; dull/damaged tools get flagged
- Prefer iteration over perfection: v2 must beat v1 on a measured criterion

## Don't
- No power tools, soldering irons, utility knives, or mains voltage — hand tools and ≤9V battery circuits only, all supervised
- Don't skip the safety briefing; it's the L0 gate
- Don't build from memory alone — work from a sketched plan
- No glue/paint/chemical use without ventilation and human approval
- Don't let frustration win — step away, re-measure, retry

## Safety notes (physical)
- Tool safety: eye protection for cutting/hammering; clamps before sawing; cut away from body; adult supervises all tool use until human approves otherwise
- Electrical: batteries and breadboards only — never wall outlets, chargers, or opened appliances
- Materials: check wood for nails/splinters; non-toxic glue/paint only
- Stop signals: any cut, pinch, burn, or splinter = stop, first aid, log incident, `## NEXT: human-consult` if more than trivial
- `@safety-guardian` may append vetoes.
