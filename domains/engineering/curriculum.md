# Engineering & Making Curriculum

> Maintained by `@domain-mentor`. The full L0→L10 path; each level lists skills, theory, and the assessment that unlocks the next level. All tool use supervised per `playbook.md` until human approves solo work.

## L0 — Foundations
- What engineers do: problem → design → build → test → improve
- Workshop rules & safety briefing; measuring with ruler and tape (mm/cm)
- Assessment: safety quiz + measure 5 objects accurately

## L1 — Hand Tools & Measurement
- Screwdrivers, pliers, hand saw (sawing straight), hammer control, clamps
- Marking out: pencil, square, measuring twice
- Assessment: cut and assemble a straight-edged scrap-wood piece to spec

## L2 — Simple Machines
- Lever, pulley, wheel/axle, inclined plane, wedge, screw — mechanical advantage
- Build demos: lever balance, string pulley lift, ramp test
- Assessment: identify all 6 machines in everyday objects + build one demo

## L3 — First Build Projects
- Paper/card engineering: bridges, towers (folding, trussing, load test)
- Wood build: small box or birdhouse from a measured plan
- Assessment: card bridge holds 1kg; box assembled square

## L4 — Fasteners & Joining
- Screws vs nails vs glue vs joinery basics; when each fails
- Dismantle/reassemble a household object (supervised)
- Assessment: teardown report + successful reassembly

## L5 — Structures — Intermediate milestone
- Triangles & trusses, compression/tension, load paths
- Span challenge: strongest beam/bridge per material budget
- Assessment: designed structure holds 5x own weight + explain why

## L6 — Electronics Basics
- Circuit, battery, switch, LED, resistor — safe low-voltage only
- Build: series/parallel circuits on breadboard, flashlight circuit
- Assessment: working switched LED circuit + draw its schematic

## L7 — Mechanisms
- Gears, cams, cranks, linkages — motion conversion
- Build: crank-driven automaton or gear toy
- Assessment: working mechanism + explain input→output motion

## L8 — Design Cycle Projects
- Full cycle on a real problem: brief → sketch → prototype → test → iterate
- Documented design notebook
- Assessment: project viva — present design, test data, v2 improvements

## L9 — Integrated Builds
- Combine structures + electronics + mechanisms in one project (e.g., line lamp with moving part, alarm box)
- Basic soldering supervised (or solder-free alternatives)
- Assessment: integrated project demo + notebook review

## L10 — Mastery
- Independent capstone: define a real household/community problem and solve it
- Teach a build workshop to a beginner
- Assessment: capstone presentation + taught session + portfolio review
