# Body Engineering Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes. Arc: **ASSESS → ENGINEER → EXCEED** — audit the machine first, then rebuild it, then exceed it.

## Next 30 days — ASSESS
- [ ] Complete the L0 machine audit: 7-day baseline (avg resting HR, avg steps/day, weight, waist) → `learner/assessments.md` + `metrics.md`
- [ ] Collect guardian-provided lab report + BP reading for the L1 audit (educational read only; out-of-range → `## NEXT: human-consult`)
- [ ] Est. VO2max via Rockport 1-mile walk or scaled Cooper test
- [ ] File the full "machine spec sheet"; name every sedentary-risk flag
- [ ] Begin Zone 2 habit: 2–3 easy sessions/week at talk-test pace (unlock L2 early if audit done)

## 60 days — ENGINEER begins
- [ ] L2 in progress: ≥3 Zone 2 sessions/week for 4 consecutive weeks
- [ ] Cardiac-drift re-test (<~10% HR rise over 30 min at constant pace)
- [ ] Start the L3 progressive-overload block in one domain (+5–10%/week, one variable)
- [ ] RHR trend recorded weekly in `metrics.md`

## 90 days — the engine proves itself
- [ ] L3 block complete: 6 compliant weeks logged, zero injury flags
- [ ] L4 combined split running: 3 Zone 2 + 2 strength sessions/week (per `domains/strength` level)
- [ ] Re-audit vs baseline: RHR trend, waist, steps, est. VO2max — the machine must show it changed
- [ ] If VO2max re-test confirms base: first scaled interval session introduced (L5 entry)

## This year — toward EXCEED
- Target L5–L6 by year-end: est. VO2max ≥5% above baseline, a sustained polarized weekly rhythm (~80% easy / ~20% hard), first light rucks (distance before load), and a documented 3-consecutive-day durability block.
- Long-horizon note: elite load benchmarks (Fan Dance ~24–26 km, Long Drag ~64 km, SFAS 45 lb ruck) are multi-YEAR aspirations — this year's rucking stays light and progressive; minors remain scaled per `learner/profile.md`.
