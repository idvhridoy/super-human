## Domain-specific KPIs
- Resting heart rate (bpm): morning average per week — the engine-idle trend; expect slow decline as the base builds. Spike >5–10 bpm over baseline = fatigue flag → check `pillars/sleep`, consider downgrade.
- Estimated VO2max: re-tested at every level gate (L1 baseline, then L2→L10). Test type recorded each time for comparability.
- Weekly volume by zone: minutes logged in Zone 1–2 (easy) vs Zone 3+ (moderate/hard) — target ~80% low / ~20% hard once L5+ (polarized/pyramidal).
- Sessions/week: 2 (audit phase) → 4–5 (engineer phase) with ≥2 rest days (hard rule via `pillars/training`).
- Ruck distance (km) and load (kg / % bodyweight): longest single ruck; progression rule — distance before load.
- Body-composition notes: weekly weight + waist; trends only — day-to-day noise ignored. Fat-loss lever is `pillars/nutrition`, not extra training.
- Activity baseline: 7-day rolling avg steps/day; sedentary flag if <~5,000.
- Lab/vital flags: count of out-of-range values noted → all go to `learner/health.md` flags via human, never interpreted here.
- Consecutive-day durability: longest run of back-to-back training days completed at planned intensity (L7+).
- PR log: 5k time, longest ruck, longest single effort — date + value each time beaten.
- Streak: consecutive days with a logged session or rest-day compliance.
