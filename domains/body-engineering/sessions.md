# Body Engineering Sessions

Chronological — newest at bottom. Two entry types: training sessions and body-audit/measurement entries.

## Session format

```
## <ISO-8601 timestamp> — session
- Duration: <min> · Intensity: <RPE 1-10> · Zone: <1-5 or easy/threshold/interval>
- Resting HR (morning): <bpm>
- Work: <session type — zone-2 / interval / ruck / durability block — + domain link e.g. running/swimming/strength>
- Load: <ruck weight, distance, or "bodyweight/none">
- Result: <what improved / what struggled>
- Next: <focus for next session>
```

## Body-audit entry format (L0–L1 and every level-gate re-test)

```
## <ISO-8601 timestamp> — body-audit
- Resting HR: <bpm, morning supine> · BP: <systolic/diastolic if device available>
- Weight: <kg> · Waist: <cm> · Steps (7-day avg): <n>
- Est. VO2max: <test used + result>
- Lab report fields noted: <LDL / HDL / triglycerides / glucose — educational read only>
- Flags: <sedentary-risk / out-of-range values → owner: self / guardian / doctor>
- Action: <next level unlocked / held / escalated>
```
