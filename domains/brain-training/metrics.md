## Domain-specific KPIs (baseline battery = L0 reference)
- Digit span: longest digit string recalled forwards (baseline: TBD → target +2 by L2).
- Word-list recall: % of 15-item list after 10 min and after 24h.
- Memory palace: items correct / items attempted; recall latency per item.
- Symbol-search / processing speed: correct items per minute; accuracy must stay ≥95%.
- Attention: longest clean focus block (min); distractions per block (target ≤2 in 15 min).
- Working memory: highest sustained level on chosen n-back-style task.
- Puzzles: graded puzzles solved within time limit; average solve time per difficulty.
- Metacognition: prediction-vs-actual calibration gap (%) across logged tasks.
- Adherence: sessions completed vs planned each week.
