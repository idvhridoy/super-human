# Brain Training Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes.

## Next 30 days
- [ ] Run the L0 baseline battery (digit span, word recall, symbol-search, attention task) — record in `metrics.md`.
- [ ] Build the first memory palace and pass the 10-item / 24-hour-apart recall test.
- [ ] Learn a 10-item peg system; start chunking drills on numbers.
- [ ] Establish the session habit: 15–20 min, 4–5 days/week, always logged.

## 60 days
- [ ] Pass L2 assessment: digit span +2 over baseline; 15-item peg recall at ≥85%.
- [ ] Complete L3 attention block: 15-min focus with ≤2 distractions for 5 straight days.
- [ ] Start L4 speed work: 2 timed drills in rotation, accuracy protected.
- [ ] First mini-benchmark re-run at day ~45 to check for early transfer.

## 90 days
- [ ] Pass the L5 Benchmark Suite: ≥3 of 5 metrics improved vs L0 baseline.
- [ ] Begin L6 logic strand: graded puzzle sets 3x/week with written reasoning.
- [ ] Write the first personal "what works for my brain" note — seed of the L8 metacognition log.
- [ ] Review with `@orchestrator`: confirm training stays playful and under time budget.

## This year
- Reach L7–L8: working-memory progression + a running prediction/calibration journal.
- Complete one full L9 self-designed 4-week protocol.
- Stretch goal: memorize something real-world useful (e.g., a poem, speech, or key number set) via palace/pegs.
