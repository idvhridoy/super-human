# Brain Training Resources

> Curated by `@knowledge-librarian`, ordered by level. Generic categories — specific titles/URLs added after librarian review (never invent links).

## L0–L2 (foundations)
- A baseline-test kit: printable digit-span sheets, word lists, symbol-search grids, simple timers.
- An illustrated beginner's guide to how memory works (kid-friendly).
- Memory-palace walkthrough videos/tutorials aimed at first-timers.
- A peg-system reference sheet (rhyming or shape pegs, 1–20).
- Chunking worksheets: numbers, spelling lists, grocery lists for daily practice.

## L3–L5 (intermediate)
- Attention-training routines: focus-block timers, distraction-log templates, beginner breathing guides.
- Processing-speed drill sets: symbol-substitution sheets, rapid-naming cards, mental-math sprint decks.
- A benchmark re-test packet mirroring the L0 battery for clean comparisons.
- Graded puzzle book series (easy → medium): sequences, mazes, beginner logic grids.
- Short reading on why sleep and exercise drive memory consolidation — links to pillars.

## L6–L10 (advanced)
- Logic puzzle collections: syllogisms, grid logic, lateral thinking, introductory proofs.
- Working-memory training programs with spaced-session schedules (used with skepticism-of-hype framing).
- Metacognition tools: prediction-journal templates, error-log formats, calibration trackers.
- A practical guide to spaced repetition and interleaving for the L9 protocol design.
- Teach-back materials: a simple lesson-plan template for the L10 "teach a technique" capstone.
- Optional deep dive: a reputable popular-science book on memory techniques and their limits.
