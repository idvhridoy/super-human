# Chemistry Resources

> Curated by `@knowledge-librarian`, ordered by level. Generic categories — no invented URLs.

## L0–L2 (foundations)
- Intro chemistry textbook chapters on matter, atoms, and the periodic table
- Free video course series covering atomic structure and periodic trends
- Interactive atom-builder and periodic-table simulations (PhET-style)
- Printable worksheets: element symbols, classification, table navigation
- Flashcard app/deck for the first 20 elements, then common ions

## L3–L5 (intermediate)
- General chemistry textbook (bonding, reactions, stoichiometry chapters)
- Balancing-equation drill generators and reaction-type worksheet packs
- Interactive simulations: molecule building, balancing, concentration/molarity
- Guided stoichiometry problem sets with worked solutions (graded difficulty)
- Mole-map reference sheet (learner-built)

## L6–L10 (advanced)
- Full general chemistry textbook (acids/bases, thermochemistry, kinetics, organic intro)
- Virtual lab simulations for titration, rates, and calorimetry concepts
- Past-exam question banks for cumulative practice
- Household-product label reading exercises (ingredient lists, safety data)
- Organic chemistry primer with naming drill sets and model-kit-style visualizers
