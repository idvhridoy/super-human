# Brain Engineering Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes.

## Next 30 days
- [ ] Complete the L0 cognitive audit — reaction ms (simple + choice), digit span, n-back entry level, sustained attention, processing speed — logged to `learner/assessments.md` + `metrics.md`.
- [ ] Run the L1 stress probe: battery subset under mild pressure; write the stress-response profile.
- [ ] Adopt the "learn after training" rule with `@training-coordinator`; protect sleep targets with `@sleep-guardian`.
- [ ] Establish the session habit: 15–20 min cognitive session, 4–5 days/week — every rep logged with score + perceived stress (1–5).

## 60 days
- [ ] Pass the L3 reaction assessment: ≥15% faster, ≥95% accuracy, sustained across 3 spaced sessions.
- [ ] Start the adaptive dual-n-back progression; log entry level + weekly level.
- [ ] First calm-vs-pressure re-test — verify the degradation delta is shrinking vs L1.
- [ ] SIT phase-1 education complete: stress model written in the learner's own words.

## 90 days
- [ ] Pass L4: +2 n-back levels + one demonstrated transfer rep.
- [ ] Pass the L5 skills check: 60-second downshift, process-goal templates, agility drills.
- [ ] Begin the L6 graded exposure ladder: first rung (distraction) logged and debriefed.
- [ ] Quarter review with `@orchestrator`: adherence, stress signals, difficulty calibration.

## This year
- Finish SIT: full exposure ladder + the L7 dual-stressor assessment.
- Build the v1 best-reaction library (≥5 scenario classes) with `@scenario-coach`.
- Reach L8–L9; teach a first drill to someone else.
- Stretch: attempt the L10 Multi-Stressor Battery as a diagnostic — pass or fail, logged honestly.
