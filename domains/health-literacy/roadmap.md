# Health Literacy Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes.

## Next 30 days
- [ ] L0 foundations + L1 body-map labeled at 80%+ → reach L1
- [ ] Vitals baseline started: resting pulse + temperature measured 3x and logged → reach L2
- [ ] "Always tell an adult" red-flag symptom list written and memorized

## 60 days
- [ ] Symptom-description drills: 5 scenarios described accurately (what/where/when/how bad) → reach L3
- [ ] Read 4 sample medicine labels at 100% + met a pharmacist intro (what they do) → reach L4
- [ ] Personal health file folder created: vaccination card, any past prescriptions/reports collected

## 90 days
- [ ] "Where do I go for X?" care-level flowchart passed → reach L5
- [ ] Prevention calendar built for the learner's age (dental, vision, vaccines — guardian reviews) → reach L6
- [ ] First mock doctor visit role-played end-to-end (prep → consult → recall)

## This year
- Reach L8–L9: complete organized personal health file, source-ranking instincts solid, confident mock visits at 85%+. Capstone (L10): learner handles a real routine check-up with minimal prompting — guardian approved.
