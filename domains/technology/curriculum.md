# Technology Curriculum

> Maintained by `@domain-mentor`. The full L0→L10 path; each level lists skills, theory, and the assessment that unlocks the next level.
> Scope rule for every level: this domain teaches **how technology works and how to judge it** — building software lives in `coding/`, building hardware lives in `engineering/`, safe daily use lives in `digital-literacy/`. Reference them, never repeat them.

## L0 — Foundations: Technology in Daily Life
- Skills: inventory the technology the learner touches in one day; sort devices by input → process → output.
- Theory: what "technology" means (tools that extend human ability); every device takes input, does something, gives output; tech has a history — each invention solved a problem.
- Assessment: tech-day map — 15+ devices/systems identified and correctly labeled input/process/output.

## L1 — Inside the Box: Chips, Sensors, Power
- Skills: identify the core building blocks inside everyday devices (processor, memory, battery, screen, sensors) at concept level.
- Theory: what a chip is (billions of tiny switches); sensors as the device's "senses"; batteries and energy; why devices get warm.
- Assessment: explain how 3 household devices work from power-on to output (e.g., microwave, remote control, thermometer) — safe verbal/written explanation, no live teardown required.

## L2 — How Computers Think
- Skills: explain binary as on/off states; trace a simple program conceptually (input → rules → output).
- Theory: hardware vs software; CPU, memory, storage roles; binary and why computers use it; an operating system as the device's manager.
- Assessment: teach-back — explain to someone what happens between pressing a key and a letter appearing on screen, using correct vocabulary.

## L3 — Networks & the Internet
- Skills: describe how a message travels device → router → across the internet → back.
- Theory: networks connect devices; packets and addressing at concept level; Wi-Fi vs wired vs mobile data; what a server is; the internet is physical (cables, data centers), not magic air.
- Assessment: draw and narrate the path of a photo sent to a friend, naming each hop.

## L4 — Cloud & Services
- Skills: distinguish "on my device" vs "in the cloud"; name what a service does with your data at a basic level.
- Theory: cloud = other people's computers running services; why companies host things centrally; accounts, sync, and where files actually live; uptime and "it just works" trade-offs.
- Assessment: cloud map — for 5 services the learner uses, state where the data lives, who runs it, and what happens offline.

## L5 — Intermediate milestone: End-to-End Explainer
- Skills: trace one complete everyday action through the whole stack — device, chip, OS, app, network, server, response.
- Theory: integration of L0–L4; systems thinking — technologies are stacks of simpler parts; failure at any layer breaks the whole.
- Assessment: written + verbal end-to-end explanation (e.g., "what happens when I send a message / watch a video") reviewed by `@domain-mentor` for accuracy at every layer.

## L6 — Gadgets & Smart Systems
- Skills: explain how sensor + logic + actuator = automation; evaluate a smart device honestly.
- Theory: IoT concept; sensors triggering actions (thermostats, lights, wearables); voice assistants as ears + cloud + speakers; convenience vs data collection trade-off.
- Assessment: analysis of one smart/automated system — what it senses, what it decides, what it does, what it learns about you.

## L7 — AI & Automation Landscape
- Skills: describe, accurately and without hype, what modern AI does and doesn't do; name where automation already runs daily life.
- Theory: AI at concept level — pattern-finding systems trained on data, not thinking minds; automation = rules + machines doing repetitive work; where AI already sits (recommendations, maps, spam filters, translation); capability vs marketing claims.
- Assessment: survey of 5 places AI/automation touches the learner's life, each with honest "what it actually does" — tool *use* and AI safety stay in `digital-literacy/`.

## L8 — Evaluating New Tech
- Skills: run a structured evaluation on a new gadget/app/service before adopting it.
- Theory: specs vs marketing; total cost (money + data + attention + lock-in); privacy trade-offs; repairability and longevity; "does this solve a real problem I have?"
- Assessment: written tech evaluation using a checklist — verdict with evidence — on a real or hypothetical product.

## L9 — Building a Personal Tech Radar
- Skills: track emerging technologies; sort them into adopt / trial / watch / hold with reasons.
- Theory: hype cycles — every new tech goes through inflated claims → disappointment → real use; sources of signal vs noise; why waiting is often the right call.
- Assessment: tech radar maintained 4+ weeks — 10+ entries categorized, each with a one-line justification.

## L10 — Mastery: Technology Judgment
- Skills: make and defend real technology decisions for self and family; teach the input→process→output framework.
- Theory: synthesis — how tech works, what it costs, when to adopt, when to refuse; technology as tools serving human goals, never the reverse.
- Assessment: capstone — complete tech-adoption framework applied to a real decision + maintained radar presented + teach-back session explaining how a chosen device works end-to-end.
