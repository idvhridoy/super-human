# Digital Literacy Roadmap

> Maintained by `@roadmap-planner`. Dates adjusted from evidence, not wishes. Assumes ~3 sessions/week + daily 10-min typing practice until L1 passed.

## Next 30 days
- [ ] Baseline audit in session 1: can learner navigate files, type, and name the parts of a URL?
- [ ] Complete L0 Device & File Basics (folder-organization test)
- [ ] Daily typing practice started; track WPM in metrics.md
- [ ] Start L2 browser skills alongside typing

## 60 days
- [ ] Pass L1 typing gate (25+ WPM at 95%+)
- [ ] Finish L2: scavenger-hunt test passed
- [ ] Into L3 research skills: query practice + source evaluation drills
- [ ] Password/passphrase lesson done early — safety before independence

## 90 days
- [ ] Finish L3 with cited mini-research task
- [ ] Complete L4 Online Safety & Privacy at 100% scenario test — unlocks supervised-independent browsing
- [ ] Digital-footprint audit started (L5 entry)
- [ ] ~38 sessions logged; safety rules applied in all other domains' tool use

## This year
- Target: through L6 media literacy and into L7 productivity tools; L9 AI-fluency after media literacy is solid
- Stretch: L8–L9 complete; learner can independently evaluate and safely use new tools
